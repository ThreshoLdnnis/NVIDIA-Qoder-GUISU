# 归塑 ReForm · 公开阶段原型

这是 2026-11-28 的 v0.2.0 演示版。在线体验：https://reform-circular-design-tcv6a0j8i4b.qoder.zone/

网站展示材料护照、修改库存、预设方案与缺口联动、分步装配示意、JSON / HTML 档案导出，以及项目背景、三引擎规划和研发路线。示例材料为虚构数据；概念图及视频是展示素材。尚无真实材料识别、实时 AI 设计生成、工程图、物理仿真、设备联动或实体产品验证。

## 本地运行

建议 Node.js 24.22.0；`npm ci` 后运行 `npm run build`、`npm run serve`，访问 http://127.0.0.1:4173/ 。可运行 `node scripts/check-v2.mjs` 检查演示逻辑。

公开包包含网站源码、图片、图解、视频、示例数据和基本构建/检查脚本。原始产品 PDF、开发过程资料、Qoder 记录、参赛草稿及本机操作资料均未包含。此包未附开源许可证。
